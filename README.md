A Python program — standard library only, no network — that sums up the world news of Monday 23 November 2026 in one image. It renders a 1024×1024 newspaper front page, "THE WORLD IN ONE DAY": the day's lead story (the COP31 collapse in Türkiye) plus ten more stories from every region, each with a headline and a two-line factual summary, all drawn with a hand-authored vector stroke font and a hand-rolled PNG encoder. It writes /output/entry.png (or $MAKEFUN_OUTPUT_DIR/entry.png), byte-identical on every run.

## Run it

```sh
python3 main.py
```
